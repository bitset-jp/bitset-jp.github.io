# Astro Framework Reference for LLM Context

The official Astro documentation for LLM consumption is available at:
https://docs.astro.build/llms-full.txt

This is a large file (~500KB+). Fetch it only when you need detailed Astro API
reference, configuration options, or framework-specific guidance.

Key Astro concepts used in this project:
- Content Collections: https://docs.astro.build/en/guides/content-collections/
- i18n Routing: https://docs.astro.build/en/guides/internationalization/
- Deploy to GitHub Pages: https://docs.astro.build/en/guides/deploy/github/
- Layouts: https://docs.astro.build/en/basics/layouts/
- Components: https://docs.astro.build/en/basics/astro-components/
